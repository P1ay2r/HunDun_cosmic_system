# 混沌宇宙公理体系

**一个自成体系的混沌宇宙世界观设定**

## 📖 项目简介

混沌宇宙公理体系是一个系统化的世界观设定项目。它从一个“混沌”的概念出发，逐步构建起包含宇宙、时空、次元、分身、物理定律和操作规则的完整公理体系。

### 核心设定

- **混沌**：一切数学结构的集合，具有自指意识
- **虚空**：不存在任何数学结构的“无”
- **宇宙**：混沌中可被意识泛函感知的部分
- **时空**：宇宙中具有度规与因果结构的连通区域
- **次元**：时空中因果历史的树形集合（多重世界分支）
- **分身**：混沌的情感投射、涂鸦与概念实验的具象化产物（共32位）

本项目以 **Obsidian** 作为主要编辑和维护工具。

- 所有 `.md` 文件均兼容 Obsidian 的双向链接语法（`[[wiki link]]`）
- 建议使用 Obsidian 打开本仓库以获得完整的阅读和编辑体验

| 工具 | 用途 |
