## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 用荒诞感刺穿一切严肃结构的表面，使宇宙中“过于紧绷”的部分松动。祂不解决问题，祂让问题“看起来没那么严重”——而当一个东西看起来没那么严重时，它也就不再那么可怕了。

### 3.2 能力模型

- **输入**：
$$
\text{Input}_{\text{丑}} = \{\text{目标情境 } C, \text{关键张力点 } P_1, P_2, \dots\}
$$
- **输出**：
$$
\text{Output}_{\text{丑}} = \{\text{情境重置 } C', \text{笑点命中率 } \eta\}
$$
- **转换函数**：
$$
\mathcal{F}_{\text{丑}}(C) = C' = \text{荒诞化}(C)
$$
其中“荒诞化”定义为：
$$
\text{荒诞化}(C) = \text{将 } C \text{ 中的必然性替换为偶然性，将严肃性替换为可选择性}
$$

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 笑点命中率 | $\eta_{\text{丑}}$ | 笑话的实际效果与预期效果的比值 | 约 $0.7\text{—}0.9$——七成能响，三成会冷 |
| 冷场恢复速度 | $v_{\text{冷}}$ | 冷场后重新组织下一句话的速度 | 极快，几乎无缝衔接 |
| 严肃瓦解距离 | $R_{\text{严}}$ | 能让周围人的严肃感显著降低的作用半径 | 约一场聚会的范围 |
| 真实表情露出概率 | $p_{\text{真}}$ | 在无人注意时露出非笑脸的概率 | $p_{\text{真}} \approx 0.01$（极低，但存在） |
| 对焚烬者“冷静时间”缩短率 | $\Delta t_{\text{焚}}$ | 小丑在场时焚烬者发火后恢复平静的时间缩短比例 | 约缩短 $30\%\text{—}40\%$ |

## 第四部分：核心哲学

### 4.1 偏好函数（笑点判定）
$$
P_{\text{笑}}(x) = \text{意外性}(x) \times \text{可共鸣性}(x) \times \text{时效性}(x)
$$

小丑偏好那些：
- 意外性极高（没人预料到）
- 可共鸣性中等（听得懂，但不会太共鸣——太共情就不好笑了）
- 时效性极强（此刻讲最有效，过一会儿就失效了）

### 4.2 关于“不好笑”的处理规则

如果笑话冷场，小丑的应对策略是一个递进序列：

1. 第一秒：摊手耸肩——表情无辜。
2. 第二秒：自嘲——“好吧，这个我回去改改。”
3. 第三秒：抛下一个——无缝衔接下一个笑话，当作刚才没发生。
4. 第四秒：如果全场持续沉默，小丑会安静下来，看着窗外，说一句无关的、不是笑话的话。然后恢复。

**没有人知道第四秒的内容是从哪来的。** 小丑自己也不解释。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：偷看说书人的书

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 小丑偷看说书人的书 |
| 起因 | 一次聚会结束后，小丑路过说书人的座位，发现书翻开着。 |
| 经过 | 小丑低头看那页书，书页是空白的——但祂听到一阵极轻的声音：是祂自己最早的笑声，还没有学会“用笑来防御”的时候。小丑合上书走了。下次聚会时，说书人说：“你上次翻到那页了？”小丑：“……嗯。”说书人：“那页是你自己的。”小丑：“我知道。” |

| 一句话定性 | 小丑一辈子都在逗别人笑——而说书人让祂听到了自己第一次笑的声音。 |

### 6.2 轻量级糗事

有一次小丑在某个次元讲了一个“宇宙级笑话”——导致整个次元的智慧生物同时笑了三分钟，笑完之后所有生物都不记得自己为什么笑了。那个次元的文明在接下来的两代人中都在试图找出“三分钟集体失忆”的原因，成立了专门的科研机构，发表了一万篇论文。小丑听说之后，说了一句：“看，这才是真正的好笑话——你都不知道它还在响。”然后祂再也没去过那个次元。

## 第八部分：一个未被写进公理但广为人知的细节

小丑的脸——那张夸张的、永远在笑的、红白相间的面孔——是**真的**。

不是画上去的。不是面具。那是祂自己的皮肤。祂的脸从一开始就是笑的。没有人知道祂为什么会这样——混沌没说过，小丑自己也不解释。祂只能一直笑下去。因为那已经不是选择了，是祂的面孔本身。

说书人有一次在一页留白上写道：“祂的脸是笑的。祂的眼睛不是。”

那页纸后来被小丑翻到过一次。祂看完了那句话，什么都没有说。只是把书合上，放回了原处。

3. **小丑自己相信“荒诞”吗？** ——还是荒诞只是一个工具？
