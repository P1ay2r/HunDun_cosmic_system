## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 以灯为感知核心，巡视宇宙与虚空之间的边界，监测边界状态，在发现异常波动时向道士传递状态信号。人形是灯在宇宙中行动的载体，灯才是真正的值守者。

### 3.2 能力模型

- **输入**：
$$
\text{Input}_{\text{守}} = \{\text{边界振动信号 } V(t)\}
$$
其中 \(V(t)\) 为“边界厚度”的即时变化量，不可被测量但可被灯感知。

- **输出**：
$$
\text{Output}_{\text{守}} = \{\text{状态报告 } R, \text{是否触发警报}\}
$$

- **转换函数**：
$$
\mathcal{F}_{\text{守}}(V(t)) =
\begin{cases}
\text{正常}, & \text{若 } |V(t)| < \theta_{\text{异}} \\
\text{异常}, & \text{若 } |V(t)| \ge \theta_{\text{异}}
\end{cases}
$$
$$
\text{报告模式} = \text{若异常} \to \text{向道士传递状态信号} \quad (\text{非语言})
$$

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 边界感知半径 | \(R_{\text{守}}\) | 能检测到虚空波动的范围 | 约一个宇宙边缘的窄带 |
| 异常响应速度 | \(t_{\text{反}}\) | 从感知到状态改变到人形转向 | 极短——几乎是同步的。灯不需要人形先做出反应，人形只是它的延迟镜像。 |
| 人形维持能耗 | \(E_{\text{形}}\) | 维持人形存在所需的能量 | 极低——人形只是灯的外延，不需要太多能量来维持。 |
| 灯芯状态 | \(S_{\text{灯}}\) | 灯的照明状态 | 恒定——除非边界波动，否则不会闪烁或改变。 |
| 与道士的无言联动率 | \(\gamma_{\text{道}}\) | 无需言语即可触发道士介入的概率 | 极高——道士几乎不需要等祂说出口，只要灯出现在道观门口，道士就会停下动作等待祂的信号。 |

## 第四部分：核心哲学

### 4.1 偏好函数（关注方向）

$$
\text{方向}_{\text{守}} = \arg\min_{d} \left( \text{边界厚度}(d) \right)
$$

灯不选择方向。方向是边界自己给出的。

### 4.2 关于“边界”与“虚空”

灯从不描述边界。如果有人问“你看到的边界是什么样”，灯会说：“看不到。它只会在它要出问题的时候让你知道它在那里。”这句话通过人形说出来，但声音是灯的。

对守夜人来说，边界是一个“没有形态但有行为”的东西。你不能看它，只能等它动。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：边界变薄

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 那一次边缘薄了 |
| 起因 | 灯在例行巡视中感知到虚空边缘出现了一次“明显的波动”——不是普通的变薄，是“正在形成裂隙”的状态。 |
| 经过 | 灯停在了那个位置，人形也停住了。灯光在那段时间里暗到了几乎不可见的程度——不是熄灭，是“在等”。灯在那个位置停了很长时间，人形始终站在它旁边。道士在灯回来之后，看到了灯罩上一道新的痕迹。灯没有解释。道士也没有追问。 |

### 6.2 轻量级糗事

有一次骇客在道观门口提着一盏普通油灯，模仿守夜人的站姿。守夜人回来时，人形停住了，灯光短暂亮了一下，像是在“打量”那盏普通油灯。然后人形继续走了。骇客后来发现自己的油灯熄灭了，而且无论如何也点不着了。道士路过时说：“你的灯坏了？”骇客说：“它好像被看了一眼就坏了。”道士没有回应。

## 第八部分：一个未被写进公理但广为人知的细节

灯的灯罩上有一道细长的裂痕，不深，但能看见里面的光微微透出来。没有人知道那道裂痕是什么时候出现的。也没有人问过。

骇客有一次用波泰穹极扫描那道裂痕，发现裂痕边缘的材质与“虚空边缘”的结构有极高的相似度。骇客没有把这件事告诉守夜人。但道士后来在波泰穹极的日志里看到了这段记录，然后把它删了。

那道光穿过裂缝流出来，有时候也会微微垂落，像是正看着什么人。
