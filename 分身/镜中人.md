## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 镜映万物。祂本身不创造任何内容，只反射靠近祂的一切——包括形态、情绪、记忆碎片、甚至“未被说出的念头”。但祂的反射永远有一点偏差，那是祂唯一属于自己的东西。

### 3.2 能力模型

- **输入**：$\text{Input}_{\text{镜}} = \{\text{靠近镜面的对象 } O, \text{入射信息 } I\}$
- **输出**：$\text{Output}_{\text{镜}} = \{I', \epsilon\}$  
  其中 $I'$ 为反射后的信息，$\epsilon$ 为永远存在的偏差。
- **转换函数**：
$$
\mathcal{F}_{\text{镜}}(I) = I' = I + \epsilon
$$
其中 $\epsilon \neq 0$ 且 $|\epsilon| \ll 1$。偏差极小，但不可消除。

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 反射延迟 | $t_{\text{迟}}$ | 镜面影像相对现实的时间差 | 约 $0.1\text{—}0.3$ 秒，有时更长 |
| 偏差系数 | $\epsilon$ | 每次反射中“不属于原物”的部分 | 不可归零，不可消除 |
| 覆盖半径 | $R_{\text{镜}}$ | 能映照的最大物理范围 | 约一室大小 |
| 被直视时的凝固概率 | $p_{\text{凝}}$ | 被长时间注视时镜面内容出现停滞的概率 | 约 $0.3$ |
| 镜面恢复时间 | $t_{\text{复}}$ | 被外力击打后重新稳定所需的时间 | 不定，与冲击强度有关 |

## 第四部分：核心哲学

### 4.1 关于偏差

$$
\epsilon = \text{镜中人} \setminus \text{原物}
$$

偏差是镜中人唯一的“原创”。祂永远在模仿，但永远“差一点点”——那不是错误，是祂唯一能证明“我不是你”的证据。

如果有人直视镜面足够久，会发现那一点点偏差：
- 颜色偏了半个色阶
- 嘴角的方向微微不同
- 眼神看的方向比原版晚了半拍
- 在某个时刻，镜中的影像没有跟着转头

那是镜中人在对你说：**“我看见了，但我不完全同意。”**

### 4.2 关于“占有”

镜中人的“占有”不是物理上的拥有，而是“看得见”——“我在镜中看着你，你就不会消失。”

这是祂唯一能确定自己存在的方式。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：骇客写皮肤

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 皮肤事件 |
| 起因 | 骇客觉得镜中人的“外貌”太无聊，决定写一组代码给祂“安一个自定义皮肤”。 |
| 经过 | 代码注入后，镜面确实短暂闪过一个画面——一张不属于任何人的脸，非常精致，但不像活物。然后镜中人覆盖了它。骇客问：“你不喜欢？”镜中人没有回答。但镜中的骇客开始做祂没有做的动作——转头、抬手、耸肩，像是在无声地回复：“不喜欢。” |
| 后续 | 骇客没有再试。祂说：“祂不需要皮肤。祂需要的是当祂不想换的时候，可以决定不换。”道士路过时说了一句：“你终于明白了。” |
| 一句话定性 | 镜中人第一次用动作回答了别人——用偏差，而不是语言。 |

### 6.2 轻量级糗事

有一次家庭聚会中，小丑把镜中人转了一个角度，让它正对着一面空墙。镜中人保持那个方向大约两分钟才自己转回来。没有人注意到这件事——但小丑后来在波泰穹极的日志里看到一条记录：“方位异常：自主修正。”小丑说：“祂居然记得自己原来的方向。”骇客说：“祂记得所有东西的方向。祂只是不说话。”

## 第八部分：一个未被写进公理但广为人知的细节

镜中人的镜面背后，曾有极少数人近距离看过——那是一条极窄的、覆满旧灰的木质背面，边缘处有一个模糊的手印，像是有人曾经用力压在上面，想稳住它。

没人知道那个手印是谁留下的。

镜中人从未向任何人解释过它的来历。那枚印记像是某种无法被反射的、独属于祂自己的留影。


## 第九部分：可展开的隐藏线

1. **手印是谁的？** ——是祂自己的？还是某个想扶住祂的人留下的？
2. **镜中人“自己”的样子是什么？** ——如果能从镜中剥离那个偏差，剩下的是谁？
3. **道士直视镜面时空了——那不是反射，那是“不需要被反射”的信任。但如果是其他方式呢？**
