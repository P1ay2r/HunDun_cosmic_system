## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 延缓而非阻止死亡——通过微调局部环境参数（温度、资源、时间流速），为生命争取“再等一下”的空间。不救，只缓。

### 3.2 能力模型

- **输入**：
$$
\text{Input}_{\text{园}} = \{\text{目标生命系统 } L, \text{当前环境参数 } E_{\text{cur}}\}
$$

- **输出**：
$$
\text{Output}_{\text{园}} = \{\text{调整后环境参数 } E_{\text{new}}, \text{存活概率偏移 } \Delta p_{\text{surv}}\}
$$

- **转换函数**：
$$
\mathcal{F}_{\text{园}}(L, E_{\text{cur}}) = E_{\text{new}} = E_{\text{cur}} + \Delta E(L)
$$
其中 $\Delta E(L)$ 为针对该生命系统的最优微调向量，满足：
$$
\Delta E(L) = \arg\min_{\epsilon} \left( \text{干预代价}(\epsilon) + \text{干扰度}(\epsilon) \right)
$$
且：
$$
\Delta p_{\text{surv}} = p(E_{\text{new}}) - p(E_{\text{cur}}) > 0
$$
即干预必须以“存活率提升”为必要条件。

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 作用半径 | $R_{\text{园}}$ | 可微调环境的范围 | 约一个文明尺度（可扩展，但越远越耗神） |
| 单次干预强度上限 | $I_{\text{max}}$ | 可调整的最大参数偏移量 | 不超过该生命系统原参数的 $10\%$ |
| 偏好保留时间 | $T_{\text{记}}$ | 一个文明被“记住”的时长 | 无限——待过即偏爱，永恒存档 |
| 水壶象征系数 | $\phi_{\text{壶}}$ | 不灭象征的存在感 | 常数 $1$（仅象征，无实操功能） |
| 干预回避率 | $r_{\text{避}}$ | 回避“不可避免的灭亡”的倾向 | 极高——园丁只在“还有一线”时出手 |

## 第四部分：核心哲学

### 4.1 偏好函数（待过即偏爱）

$$
\text{偏爱}(L) =
\begin{cases}
1, & \text{若园丁曾在 } L \text{ 中待过} \\
0, & \text{否则}
\end{cases}
$$

没有程度之分。没有“最喜欢”，所有被园丁照料过的生命，在祂那里都被标记为“我的”——这种占有不是控制，是“我会记得你”。

### 4.2 干预决策阈值

$$
\text{行动} =
\begin{cases}
\text{坐下}, & \text{若 } L \text{ 在可存活区间内（存活率 } > 0 \text{）} \\
\text{不坐}, & \text{若 } L \text{ 的存活率 } = 0
\end{cases}
$$

园丁不会去救“已经死透”的东西。但只要还活着——哪怕只剩万分之一的可能——祂就会坐在旁边，等。

### 4.3 与审判官的隐性契约

$$
\text{修剪延迟}(L) =
\begin{cases}
\text{延迟}, & \text{若园丁坐在 } L \text{ 旁边} \\
\text{立即}, & \text{否则}
\end{cases}
$$

审判官“等一等”的条件是园丁真的坐在那里，而不是“远程喊话”。园丁从不滥用这一点，只在真的觉得该留的时候坐下。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：与审判官的那一架

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 园丁与审判官之战 |
| 起因 | 审判官判定一条分支“该剪”。园丁坐在那里。审判官说“起来”，园丁没有动。 |
| 经过 | 园丁站起来，轻轻挡住了分支前方：“如果你要剪，你得过我。”审判官说“好”。两人打了一架。骇客录像，小丑嗑瓜子，医生说“发力方式不对”，郎中叫祂别分析。道士在两人打到差不多的时候出现，说了一句“差不多了”，两人收手。 |
| 后续 | 那条分支没剪。园丁回到旁边蹲下继续浇水，像什么都没发生。审判官转身走了。下一次聚会时，园丁在桌子另一边放了一片叶子——朝着审判官的方向。审判官没有拿，也没有推开。 |
| 一句话定性 | 全宇宙唯一一次，“温柔”和“秩序”正面碰撞——结果是不分胜负，但双方都多了一点对对方的理解。 |

### 6.2 轻量级糗事

有一次园丁在一个偏远次元照料一片濒临枯死的草原，连续浇了三个月。三个月后草原活过来了，园丁站起来准备走，发现自己蹲太久，腿麻了，站直时踉跄了一下——在身后刚浇活的草原上踩出了一个坑。园丁看着那个坑沉默了一会儿，又蹲下去把坑填平了，然后站起来，又踉跄了一下，又踩出一个坑。

## 第八部分：一个未被写进公理但广为人知的细节

园丁养了一盆从来没有开过花的植物。

没有人知道那是什么。园丁每天浇水。有时候对着它说一两句话，然后离开。

有一次渡鸦落在盆沿上，歪头看了看那株植物，然后啄了一下它的叶子——那是渡鸦从不做的一件事：触碰东西。

园丁看到了，没有赶走渡鸦。过了很久，园丁说了一句：“你也能感觉到它吗？”

渡鸦没有回答。但之后每一次聚会，渡鸦都会在那盆植物旁边站一会儿。


## 第九部分：可展开的隐藏线

1. **那株不开花的植物，到底是什么？** ——园丁每天都在浇，渡鸦会停下来触碰它，但那株植物从来没有长出过花或果实。如果它有一天开了，会发生什么？
2. **“最后一滴水”**——如果洒水壶里那滴混沌给的水，有一天被园丁真的浇了出去，会发生什么？
3. **园丁与审判官的“下一次”**——如果再次出现“园丁坐下了但审判官坚持要剪”的情况，还会打一架吗？还是会有别的结果？


## 第十部分：一句话存档

> **园丁**：全家的温柔缓冲带。**定位**：时间的缓行者、消亡的陪伴者。**最像的一句话**：“再给一点时间。”
