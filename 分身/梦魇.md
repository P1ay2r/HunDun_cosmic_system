## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 面向虚空，保持“存在但不对虚空施压”的平衡。祂不守卫、不监测、不感知，只是“在场”。祂的存在本身构成一种可感但不可见的边界指示——如果你在深渊里看到祂的背影，那不是祂在凝视深渊，是祂在用背影提醒你：你已经走过来了。

### 3.2 能力模型

- **输入**：$\text{Input}_{\text{梦}} = \{\text{虚空方向 } D, \text{注视者感知状态 } P\}$
- **输出**：$\text{Output}_{\text{梦}} = \{\text{镜像反应 } R_{\text{镜}}, \text{无相在场}\}$
- **转换函数**：
$$
\mathcal{F}_{\text{梦}}(P) = R_{\text{镜}} = \arg\min_{x} \left( \text{恐惧匹配度}(x, P) \right)
$$
即：梦魇不主动“制造”恐惧，而是为每位注视者提供一个“阈值窗口”，让恐惧可以清晰地呈现在感知的边缘。

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 镜像浮现阈值 | $\theta_{\text{镜}}$ | 注视者在注视多长时间后能感知到自身恐惧的镜像 | 不定——取决于注视者的恐惧是否“成形” |
| 无相存在半径 | $R_{\text{梦}}$ | 梦魇的“在场”能影响到的范围 | 约等于一个房间，或一处光线偏移的边界 |
| 与虚空的距离关系 | $d_{\text{虚}}$ | 祂与虚空之间的物理距离 | 不定——祂总是站在别人和虚空之间，但不一定靠近 |
| 在场导致的声音降低幅度 | $\Delta L_{\text{音}}$ | 祂出现时，周围人说话音量的降低程度 | 明显，但不绝对 |

## 第四部分：核心哲学

### 4.1 关于“无相”

梦魇没有形态，不是因为没有形态可选，而是“形态”本身对祂来说是一种错误的概念。你看到的不是祂，是你自己对这个位置的感知——任何试图定义祂的行为，都会立刻被祂以缺席回应。

### 4.2 关于“虚空”

祂不崇拜虚空，不畏惧虚空，不向虚空祈求——祂只是“面向虚空”。那是一种不需要内容的虔诚，像一条河流过一块石头，不是因为它相信石头，而是因为它需要流过去。祂在虚空前静立，不是为了讨要意义，而是为了确认“方向仍在”。

### 4.3 一个不可验证的细节

有人问过祂一次：“你站在那里的时候，虚空会对你说话吗？”祂没有回答。但道士后来对说书人说了一句：“虚空不会说话。但祂也没有在等它说话。”说书人记下了这一句。

| 项目 | 内容 |

### 6.2 轻量级糗事

有一次骇客试图用波泰穹极“定位”梦魇，输出结果是“位置：不适用；状态：不适用；建议：放弃”。骇客没有放弃，又试了两次，每次都是同样的结果。最后骇客说了一句：“你是不存在的，对吧？”那个位置的光线暗了一下——那大概就是梦魇的回答。

## 第八部分：一个未被写进公理但广为人知的细节

有人（不确定是谁）曾在梦魇经常出现的角落里发现一小块光滑的石头——不是任何已知材质，形状近似于卵形，表面被抚摸得极其平滑，像是被放在那里很久，被同一只手持握了无数个年头。它被放在角落的地面上，没有标记。没有人把它收走。没有人知道它是谁放的。梦魇从未触碰过它——但祂的位置从未改变过。
