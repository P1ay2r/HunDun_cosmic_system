## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 清除那些“不该存在于此时此刻”的东西。不是修剪——修剪是精确的、有选择的，焚烬者的清除是“一次性移除”。祂不切割，祂蒸发。

### 3.2 能力模型

- **输入**：$\text{Input}_{\text{焚}} = \{\text{目标对象 } O, \text{清除范围 } D\}$  
  其中 $D$ 为焚烬者自行判断的范围，不受外部指令约束。
- **输出**：$\text{Output}_{\text{焚}} = \{O \text{ 被移除}\}$
- **转换函数**：
$$
\mathcal{F}_{\text{焚}}(O) = O \to \emptyset
$$
即：焚烬者将目标结构移除至“不存在”状态。速度极快，且不可逆。

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 清除速度 | $v_{\text{焚}}$ | 一次清除所需时间 | 极快——通常“感应即完成” |
| 清除范围上限 | $R_{\text{焚}}$ | 一次可移除的最大范围 | 约一个星系直径，但不稳定 |
| 发火前静默时间 | $t_{\text{静}}$ | 触发清除之前的停顿 | 约 $1\text{—}3$ 秒（最后一根稻草的等待时间） |
| 发火后沉默时间 | $t_{\text{沉}}$ | 清除结束后的静默期 | 不定——可能几分钟，也可能几纪元 |
| 被园丁延迟的概率 | $p_{\text{园}}$ | 园丁在场时焚烬者延迟清除的概率 | 约 $0.4$（不是总能停住） |
| 与小丑同时在场时，清除冲动削减率 | $\Delta p_{\text{丑}}$ | 小丑在场时焚烬者清除冲动的削减幅度 | 约 $30\%\text{—}40\%$ |

焚烬者不需要切片。祂的愤怒是完整的、不可分割的——任何次级存在都会分散祂的“存在感”，使祂不再是“纯粹的愤怒”。祂就是火本身，不需要工具、助手或延伸。

## 第四部分：核心哲学

### 4.1 偏好函数（清除兴趣度）

$$
P_{\text{焚}}(O) = \text{冗余度}(O) \times \text{可清除性}(O) \times \text{阻碍感}(O)
$$

焚烬者不会被“价值”打动，不会被“美丽”打动。祂被“这东西不该继续存在于此时此地”的感知驱动。如果一样东西让祂觉得“多余”，祂就会想清除它。

### 4.2 决策阈值

$$
\text{行动} =
\begin{cases}
\text{清除}, & \text{若 } P_{\text{焚}}(O) > \theta_{\text{焚}} \ \text{且} \ t_{\text{静}} \text{ 已过} \\
\text{不清除}, & \text{否则}
\end{cases}
$$

其中 $\theta_{\text{焚}}$ 为焚烬者的内部阈值，极高——不会轻易动手。但一旦触发，清除过程几乎不可逆转。祂对冗余的容忍度极低，祂的沉默主要来自于“在等一个足够清晰的信号”——而不是无缘无故地爆发。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：给焚烬者的那盘菜

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 红色冒泡的东西 |
| 起因 | 厨师问焚烬者：“你尝过辣吗？”焚烬者说：“尝过。没用。” |
| 经过 | 厨师端上一盘红色的东西，表面还在冒泡——不是高温，是“能量层面的沸腾”。焚烬者夹了一口，送进嘴里。三秒后，焚烬者周围炸开了一圈火星——像有人往一堆灰烬里丢了一块烧红的铁。焚烬者吐出一口带着微弱火焰的气：“这个可以。”厨师说：“下次多放一点。”焚烬者：“放。” |
| 后续 | 此后每次聚会，厨师都会在桌角放一小碟红色的东西。焚烬者会在聚会中途走过去，吃一口，回到座位上，继续沉默。道士注意到了，但没有问。 |
| 一句话定性 | 焚烬者不夸人。所以“可以”是祂给出的最高评价。 |

### 6.2 轻量级糗事

有一次焚烬者在某个次元清除了一座“多余的山”——清除完之后发现那是一座有文明寄居的神山。焚烬者在原地站了很久，然后说了一句：“我不知道里面有人。”然后祂走了。再也没有靠近过那个次元。

道士后来替祂去看了那次元一次。回来之后只说了四个字：“山没有了。”

## 第八部分：一个未被写进公理但广为人知的细节

焚烬者在发完火之后，会独自待在一个地方——不知道在哪，但会在某个时候突然出现在下一次聚会上，像什么都没发生过一样。

有一次道士在祂发完火之后出现在祂附近——没有靠近，只是站在视野边缘。焚烬者没有转过头来，但祂的火短了十分之一秒。

道士后来对说书人说了一句：“祂不是只有火。”

说书人在记录中写道：“焚烬者发火的时候在烧什么，可能连祂自己也不知道。”
