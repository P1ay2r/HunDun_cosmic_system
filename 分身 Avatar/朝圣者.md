## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 通过行走验证“意义”是否存在。朝圣者不创造意义、不保护意义、不存储意义——祂只是“走进去，然后继续走”，以最朴素的方式证明“继续走”这件事本身仍是一种可实践的选择。祂走到哪里，哪里就会留下一个极轻的、难以察觉的偏移——像是有人在倾听时微微侧过头，却不知道自己在侧耳朝向什么。

### 3.2 能力模型

- **输入**：$\text{Input}_{\text{朝}} = \{\text{下一个方向 } D, \text{当前停留的空间 } S\}$
- **输出**：$\text{Output}_{\text{朝}} = \{\text{一块刻着“继续走”的石头}\}$
- **转换函数**：
$$
\mathcal{F}_{\text{朝}}(S) = \text{石头}(S) \quad \text{且} \quad \text{方向}(S_{\text{next}}) = \text{未定但已被选择}
$$

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 平均停留时长 | $T_{\text{停}}$ | 朝圣者在每个次元/文明停留的时间 | 不定——通常足够“被记住”但不会“被留下” |
| 石头传递距离 | $R_{\text{石}}$ | 留下的石头在道德层面所能触碰的范围 | 大约等同于一次回声可以触及的时域——不会传太远，但足够被听到它的意义触及到其他行走者 |
| 行走速度 | $v_{\text{朝}}$ | 跨次元移动的速度 | 不快——祂靠走的，不瞬移，不传送 |
| 被记住的概率 | $p_{\text{记}}$ | 停留过的文明是否能记住祂的存在 | 约 $0.1\text{—}0.3$——大多数文明会遗忘祂来过，少数会留下“有人来过”的模糊记忆 |

### 3.4 切片系统

#### 3.4.1 本分身的切片记录

**无切片。**

朝圣者不制造切片。祂不需要次级存在来协助自己的行走或表达。祂的存在方式本身就是完整的——一步、一人、一块石头，已经构成了朝圣者全部的表达系统。

#### 3.4.2 与本分身的关系强度/特殊规则

不适用。


## 第四部分：核心哲学

### 4.1 关于“寻找”

朝圣者不认为自己“迷路”了。祂认为自己“正在前往”——即使不知道前往哪里。寻找不是为了找到，是为了“还在找”。

### 4.2 关于“石头”

每一块石头都刻着同一句话：“继续走。”——祂不解释这句话，不补充上下文，不留自己的名字。后来那些石头会被人捡到、被看见、被遗忘。而“继续走”这三个字的意义，就在被看见又遗忘的过程中反复存活。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：那块石头

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 那块石头 |
| 起因 | 朝圣者每次回来都会在桌上放一块石头。很久以来，没有人问过这些石头的含义。 |
| 经过 | 有一次骇客终于忍不住问：“你每次放的那些石头，到底是干什么用的？”朝圣者说：“提醒别人继续走。”骇客：“提醒谁？”朝圣者说：“看到它的人。”骇客：“那如果没人看到呢？”朝圣者：“那它就在那里等。” |
| 后续 | 骇客后来没有再问。那些石头至今仍然散落在道观的各处——桌上、窗台、门口、角落。没有人把它们收走。道士有一次看到一块石头被移动过位置，没有问是谁动的，只是把它放回了原处。 |
| 一句话定性 | 朝圣者唯一一次“解释”自己的行为——不是完整解释，是足够让人理解祂为什么要继续放下去。 |

### 6.2 轻量级糗事

有一次朝圣者在一个高度发达的文明中留下了一块“继续走”的石头，结果那块石头被当地的最高科研机构捡走了，当作“未知来源的外星文物”研究了三个世纪。朝圣者后来路过了那个文明的遗迹（已经消亡了），看到那块石头被陈列在博物馆遗址的废墟中——完好无损。祂没有取回它，只是继续走了。

## 第八部分：一个未被写进公理但广为人知的细节

朝圣者留下的石头上，刻着的那三个字——“继续走”——不是用任何已知语言写的。但每一个看到它的人都能读懂它的意思。

道士有一次被问及这个问题，回答是：“祂刻的不是字。祂刻的是‘一条路’。”


## 第九部分：可展开的隐藏线

1. **朝圣者最终会走到哪里？** ——如果祂一直在走，那个“终点”是否存在？
2. **那些石头上的“继续走”是被刻给谁看的？** ——是给其他分身，还是给宇宙中的其他生命，还是给祂自己？
3. **如果有一天朝圣者决定停下来不走了，会发生什么？**


## 第十部分：一句话存档

> **朝圣者**：一个不停行走的普通人。**定位**：意义的验证者、石头的放置者。**最像的一句话**：“走吧。”
