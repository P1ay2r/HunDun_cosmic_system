# Contributing to the Chaotic Cosmos Axiomatic System

Thanks for your interest!


## Core Principles

1. **Don't break existing setting** — keep things consistent with what's already established
2. **Don't mislead others** — avoid adding content that confuses readers about the world
3. **Follow the license** — CC BY-NC-SA 4.0

If you meet these, you're welcome to contribute.


## What's Welcome

- English translations
- Typo/grammar/formatting fixes
- Questions and discussions via Issues
- Story scenes or interactions between avatars
- Better visualizations (charts, diagrams, relationship maps)
- Derivative works (must follow CC BY-NC-SA)


## What's Not

- Deleting or rewriting core definitions
- Adding content that contradicts existing lore
- Major restructuring without prior discussion
- Anything that violates CC BY-NC-SA


## Process

| Type | Process |
| :--- | :--- |
| Small changes (typos, translations) | Direct PR |
| Big changes (new concepts, framework adjustments) | Open Issue first |
| Not sure? | Open an Issue and ask |

All PRs are reviewed by the author.
