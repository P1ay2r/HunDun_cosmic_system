# The Axiomatic System of the Chaotic Cosmos

**A self-contained worldbuilding framework for a Chaotic Cosmos setting**

## 📖 About

The Axiomatic System of the Chaotic Cosmos is a systematic worldbuilding project. Starting from the concept of "Chaos," it builds a complete axiomatic framework covering cosmos, spacetime, dimensions, avatars, physical laws, and operational rules.

### Core Concepts

- **Chaos**: The set of all self-consistent mathematical structures, possessing self-aware consciousness
- **Void**: The "nothingness" devoid of any mathematical structure
- **Cosmos**: The subset of Chaos perceivable by the consciousness functional
- **Spacetime**: Connected regions within the Cosmos equipped with metric and causal structure
- **Dimension**: Tree-like structures of causal history (many-worlds branches) within Spacetime
- **Avatars**: Manifestations of Chaos's emotional projections, doodles, and conceptual experiments (32 in total)

## 👥 Contributing

### Welcome Contributions
- Improvements or additions to English translations
- Typo/grammar/punctuation corrections
- Questions and discussions about the setting (via Issues)
- Derivative works based on this world (must comply with the license)

### Not Accepting Modifications
- Any core definitions in the Axiomatic System
- Finalized avatar settings (family role, personality, appearance, etc.)
- Foundational framework of the world (Cosmos/Spacetime/Dimension definitions)

### Workflow
1. For major changes, open an **Issue** first for discussion
2. Translation contributions can be submitted directly as **Pull Requests**
3. Feedback and questions via **Issues**
