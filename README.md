## 📖 About

The Axiomatic System of the Chaotic Cosmos is a systematic worldbuilding project. Starting from the concept of "Chaos," it builds a complete axiomatic framework covering cosmos, spacetime, dimensions, avatars, physical laws, and operational rules.

### Core Concepts

- **Chaos**: The set of all self-consistent mathematical structures, possessing self-aware consciousness
- **Void**: The "nothingness" devoid of any mathematical structure
- **Cosmos**: The subset of Chaos perceivable by the consciousness functional
- **Spacetime**: Connected regions within the Cosmos equipped with metric and causal structure
- **Dimension**: Tree-like structures of causal history (many-worlds branches) within Spacetime
- **Avatars**: Manifestations of Chaos's emotional projections, doodles, and conceptual experiments (32 in total)
