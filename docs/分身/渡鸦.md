## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 通过“在场”维持混沌宇宙中最古老的一层信任。祂不做任何事，不改变任何事，不决定任何事——祂只是“还在相信”。

### 3.2 能力模型

- **输入**：$\text{Input}_{\text{渡}} = \{\text{环境中存在的其他存在 } E_1, E_2, \dots\}$
- **输出**：$\text{Output}_{\text{渡}} = \{\text{信任信号 } T, \text{在场记录}\}$
- **转换函数**：
$$
\mathcal{F}_{\text{渡}}(E) = T_{\text{存在}} = 1 \quad \text{除非存在明确证据不信任}
$$

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 信任衰减速度 | $\Delta T$ | 被背叛后信任恢复的时间 | 不定——有时极快，有时可能很慢，但这与祂的选择有关，而非祂的能力 |
| 形态稳定性 | $S_{\text{形}}$ | 保持实体形态的时间占比 | 约 $0.6\text{—}0.8$——经常在实体与光点之间切换 |
| 与道士的互动频率 | $f_{\text{道}}$ | 渡鸦停在道士附近的频次 | 极高——道士是渡鸦最喜欢停的位置之一 |
| 被保护概率 | $p_{\text{护}}$ | 其他分身主动保护渡鸦的概率 | 约 $0.95$（几乎全部） |

### 3.4 切片系统

#### 3.4.1 本分身的切片记录

**无切片。**

渡鸦不制造切片。祂不需要次级存在——祂的存在本身已经足够轻、足够近、足够完整。任何额外的结构都会让这份“最原始的信任”变得多余。

#### 3.4.2 与本分身的关系强度/特殊规则

不适用。


## 第四部分：核心哲学

### 4.1 关于“信任”

渡鸦的信任不是一种选择——祂的存在本身就是“信任”这种状态的化石。在混沌学会“怀疑”之前，信任是唯一的状态。渡鸦没有“选择信任”，祂只是“还在”。

### 4.2 关于“停留”

渡鸦不会在同一个地方停留太久。不是因为不安，是因为祂相信“每一个方向都有值得看的东西”。祂的移动不是寻找，是“确认”：你还在，他在，那些方向都还在。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：与焚烬者的那一次

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 那一次靠近 |
| 起因 | 一次聚会中，渡鸦从道士肩头飞起，落在焚烬者附近的桌沿上。 |
| 经过 | 焚烬者没有移动。渡鸦歪头看了祂一会儿，然后向前跳了一小步——更靠近焚烬者。焚烬者的火焰在那段时间里短了一截——不是熄灭，是“矮了一点”。渡鸦停了一会儿，然后飞回道士那边。焚烬者没有说话。道士也没有提起。但之后每一次聚会，焚烬者都会在桌角留出一小片空位——不靠近，不解释。渡鸦偶尔会落在那片空位边缘。 |
| 后续 | 那片空位从此没有被任何其他东西占据。没有人提起过。但桌角的图案中，它的存在一直保留着。 |
| 一句话定性 | 焚烬者不会为任何人腾出空间——唯独渡鸦例外。 |

### 6.2 轻量级糗事

有一次骇客试图用波泰穹极“翻译”渡鸦的叫声，输出的结果是：“音调：平稳。含义：无可识别。建议：不要翻译。”骇客没有放弃，又试了两次，每次都是同样的结果。最后骇客说：“你发出的声音根本不携带任何数据，对吧？”渡鸦歪了一下头，然后飞到了骇客的显示器上站着。骇客没有赶祂走。

## 第八部分：一个未被写进公理但广为人知的细节

渡鸦的羽毛不是真正的羽毛——它们是信任的“形态”。当渡鸦掉下一根羽毛时，那根羽毛会在落地之前自行消散，不会留下任何物理痕迹。但如果有人在那根羽毛消散前伸手接住它，它会短暂地停留在手掌中，像一片极轻的、正在变淡的灰。然后它会消失。

没有人知道那根羽毛消失后会去哪里。
