## 第三部分：核心能力/职能（公式化）

### 3.1 职能定义

> 在万物之间编织连接——跨越次元、时间线、意识、能量与意义之间的缝隙，使原本彼此孤立的事物产生接触、交织或命运上的重叠。她创造的不是强行捆绑的因果，而是微小但真实的关联。

### 3.2 能力模型

- **输入**：$\text{Input}_{\text{织}} = \{\text{两个（或多个）待连接的对象 } A, B, \dots, \text{连接类型 } T\}$
- **输出**：$\text{Output}_{\text{织}} = \{\text{连接建立}, \text{线头状态}\}$
- **转换函数**：
$$
\mathcal{F}_{\text{织}}(A, B) = A \leftrightarrow B
$$
即：在 $A$ 与 $B$ 之间引入一条新的关联，使二者在因果或感知层面产生“可被感知的靠近”。

### 3.3 关键参数表

| 参数 | 符号 | 含义 | 约束 |
| :--- | :--- | :--- | :--- |
| 织网半径 | $R_{\text{织}}$ | 能触及的最大连接范围 | 理论上可达宇宙边界，但越远所需的时间越久 |
| 单次连接耗时 | $t_{\text{织}}$ | 从“准备入针”到“线头固定”所需时间 | 不定——简单连接短，复杂关系长 |
| 连接深度系数 | $\eta_{\text{织}}$ | 连接完成后，两端的“感应强度” | 由织网者自行判断，部分连接极浅，部分较深 |
| 断线容忍度 | $\delta_{\text{断}}$ | 她能接受的自然断裂程度 | 极高——她清楚许多连接不会持续很久，只会说一句“该断的，它会断” |
| 与说书人的情报同步率 | $\gamma_{\text{说}}$ | 她织出的连接是否被记录 | 说书人偶尔也会记录这些连接——但并不总是能跟上她织线的方向 |

## 第四部分：核心哲学

### 4.1 关于“连接”

> “不是所有东西都该连在一起，但它们都该有‘可以连’的可能。”

她不会强行把两块不该相接的结构缝合——但她会让它们之间留有一段线。这段线可以收紧，也可以松开，可以由它们自己决定。

### 4.2 关于“线”

她的线不是物质，不是能量，不是信息——是一种“可以被感知的靠近”。当两件事物之间有一根线时，它们会在某些关键节点上靠近彼此，而无需知道原因。

## 第六部分：经典事件 + 糗事

### 6.1 经典事件：缝合那次裂隙

| 项目 | 内容 |
| :--- | :--- |
| 事件名称 | 那次缝合 |
| 起因 | 某次边界边缘出现了一道微小但持续的裂隙，不致命，但会让虚空中的微弱波纹渗入宇宙。道士来看了一眼，然后去找了织网者。 |
| 经过 | 织网者坐到那道裂隙旁边，没有织什么复杂的结构，只是把毛线的一端垂入缝隙，然后开始绕针。她织得很慢，不像是“修复”，更像是在给那道缝隙“做一条边”。完成之后，她把线头收在裂隙上方，打了个结。她说：“这样它就不会再撑大了。”道士说：“能管多久？”她说：“不知道，但线还在，就能撑住。” |
| 后续 | 那道裂隙没有再扩大过。道士偶尔会路过看一眼——线还在，结还在。 |
| 一句话定性 | 织网者最接近“修补”的一次操作——不是永久修复，是“让它在有线的期间不会再裂开”。 |

### 6.2 轻量级糗事

有一次她在道观窗边织东西，织着织着睡着了，针和线都垂在膝头，线头滑落到地面，沿着门槛的方向延伸了一小段。没有人动它。她醒来看见了，把它收回来，没说什么。

## 第八部分：一个未被写进公理但广为人知的细节

她的毛线团里藏着一根没有织过的线头。那根线的颜色是她从不明说的一种深灰，不显眼，不放光，不和她手中的任何工作连接。它只是被藏在团里，没有起始端，也没有目的地。

有一次骇客注意到它，问：“这根线是织什么的？”织网者说：“还没想好。”骇客：“那它为什么在这里？”织网者：“等一个想好的时候。”骇客没有追问。


## 第九部分：可展开的隐藏线

1. **那根“没有织过”的线是留给谁的？**

3. **如果有一天线断了——不是自然断，是被人剪断的，她会怎么做？**
